# LazyOS

**Think More. Do Less. Human Intent. AI Execution.**

一份 AGENTS.md，任何 AI 都能用。支援 Claude Code、OpenAI Codex、Google Antigravity。

## 使用

1. 下載 [AGENTS.md](AGENTS.md)，放進你的工作目錄。
2. 在該目錄啟動 AI，直接交代任務。
3. 專案專屬的指引寫在 `<!-- LAZYOS:END -->` 這一行下面。

同一目錄不要另外放 CLAUDE.md 或 GEMINI.md，否則部分平台會改讀它們而忽略 AGENTS.md。

## 更新

對 AI 說「更新 LazyOS」。AI 會從檔案開頭標記裡的來源取得新版，只替換 `LAZYOS:BEGIN` 與 `LAZYOS:END` 之間的內容，專案指引保持不動。

版本記錄見本儲存庫的 Git 標籤。
